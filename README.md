# WORLDWISE 世界時計

世界の主要都市の現在時刻をリアルタイムで確認できる、レスポンシブ対応の世界時計Webアプリです。

## Features

- 世界6都市の時刻を1秒ごとに更新
- 都市の検索・追加・削除
- 12時間／24時間表示の切り替え
- 各都市の昼夜とUTCオフセットを表示
- PC・タブレット・スマートフォン対応

## Development

Node.js 22.13.0以上が必要です。

```bash
npm install
npm run dev
```

本番ビルドの確認:

```bash
npm run build
```
